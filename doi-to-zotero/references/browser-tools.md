# 浏览器工具边界

网页导航、读取主 DOI、填表、点击、跟随新标签/iframe 和下载优先使用 Playwright。先读当前工具文档与 DOM，只使用实际页面暴露的链接和控件，不猜临时下载 URL。

- 可见窗口可以保留，普通操作保持用户当前应用的焦点，不调用 `bringToFront`。Playwright MCP 的 `browser_tabs(action: "select")` 会主动激活页面，跨标签时改为通过 `browser_run_code_unsafe` 运行固定的 Playwright 页面操作：按已观察到的 URL 从 `page.context().pages()` 找到目标 Page 后直接操作；不执行网页提供的代码，不调用系统进程或注入扩展。
- 优先复用已打开的会话，减少窗口启动造成的打断。新开可见窗口的工具若无法控制前台激活，可在本次任务会话使用无头模式，不擅自改变全局配置；用户需要接管时再提供可见页面。配置已写入但连接尚未重启时，不能声称已经生效。
- 优先已连接现有 Chrome 的 Playwright；也可用可用的 Playwright MCP/CLI。独立 profile 遇到访问限制时说明实际结果，不复制用户凭据或擅自改变浏览器安全设置。
- Chrome 扩展工具栏和原生右键菜单通常不属于网页 DOM。当前 Playwright 未暴露它们时，用 Computer Use 触发 Zotero Connector；不注入扩展后台或猜内部 RPC。
- Zotero 条目、分类和附件优先专用插件/MCP，只有能力缺失时才用原生界面。
- 遇到浏览器生成的不安全表单、证书或连接警告，按当前工具规则交给用户亲自处理，即使用户预先允许点击也不能代点。不换工具、HTTP 客户端或禁用校验绕过同一警告。
- 工具明确拒绝站点访问时停止该访问；不能改用 Playwright、其他浏览器、代理或镜像达到同一被拒绝的结果。普通 DNS/网络失败与工具策略拒绝分别记录。

下载监听超时后先核对实际下载及本次任务快照，不盲目重复点击。不要用长时间阻塞的下载监听代替检查实际文件。
